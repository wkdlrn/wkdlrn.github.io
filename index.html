책빵 프로젝트

JPA N+1 문제 해결 · API 성능 최적화

-90% 응답시간
문제 상황

리뷰 목록 API에서 응답 속도가 최대 20초까지 지연되며 사용자 경험과 서비스 신뢰성이 크게 저하됨.

조치 사항

SQL 로그를 확인하여 JPA N+1 문제를 식별하고, 쿼리 흐름과 구조를 재설계.
Fetch Join, @EntityGraph를 적용해 불필요한 쿼리 실행을 최소화하고, Pageable을 개선해 필요한 데이터만 효율적으로 가져오도록 수정.

성과
평균 응답속도 1~2초로 단축 (90% 감소) DB 서버 CPU 사용률 85% 감소 Prometheus + Grafana 모니터링 적용
Java Spring Boot JPA Fetch Join Prometheus Grafana
인프라 · 검색 · 아키텍처

월정액인생 프로젝트

주문 관리 시스템 · 무중단 배포 · 대용량 검색 · 퍼사드 패턴

+120% RPS 향상

① 무중단 배포 파이프라인 구축

문제 상황

Jenkins 단독 운영 시 빌드·배포 과정에서 리소스 사용량 증가와 배포 지연, 서비스 끊김 현상이 발생할 위험이 있었음.

조치 사항

CircleCI를 추가로 도입해 Jenkins는 배포, CircleCI는 Docker 이미지 빌드 및 DockerHub 푸시를 전담하도록 역할 분리.
Blue-Green 배포 전략을 적용해 무중단 서비스를 구현.

성과
빌드 부하 분산 서비스 중단 없는 배포 환경 구축 파이프라인 안정성·확장성 확보

② 대용량 검색 시스템 개선

문제 상황

상품 수 20,000건 이상인 시스템에서 JPA Like 검색은 초성 검색 불가, 영↔한 변환 불가, 신규 데이터 실시간 반영 어려움.

조치 사항

Elasticsearch 도입 및 커스텀 분석기 구성. 초성 검색, 영↔한 변환 검색 구현.
Logstash + ConfigMap으로 MariaDB와 실시간 동기화 설계 (1분 주기).

성과
RPS 50 → 110 (120% 향상) 검색 정확도·속도 향상 초성·영한 변환 검색 지원

③ 퍼사드 패턴을 통한 시스템 구조 개선

문제 상황

정기구독 결제 시스템에서 결제, 빌링키, 구독, 정산, 이메일 등 6개 서비스가 복잡하게 얽혀 트랜잭션 경계가 불명확하고 결합도가 높아 유지보수와 확장이 어려운 구조.

조치 사항

결제 프로세스를 시퀀스 다이어그램으로 시각화하여 전체 흐름 파악.
결제 검증, 구독 조회, 빌링키 복호화, 정기결제 예약을 하나의 PaymentFacade로 통합하고 트랜잭션을 퍼사드 레벨에서 일관되게 관리.

성과
컨트롤러 코드 약 70% 감소 서비스 간 결합도 감소 단위 테스트 작성 용이
Java Spring Boot Elasticsearch Logstash Jenkins CircleCI Docker Blue-Green MariaDB

CI/CD 자동화 배포 시스템

Agentica 기반 AI Agent · 대화형 자동 배포

+18%p API 성공률

① 대화형 자동 배포 시스템 (Agentica 기반)

문제 상황

배포 과정이 특정 인원에게만 집중돼 업무 불균형과 협업 효율 저하 발생. Agentica가 Swagger 문서 실행 결과를 개발자 전용 JSON 형태로만 제공하는 문제.

조치 사항

Agentica 기반으로 자연어 명령("새 버전 배포해줘")을 해석해 Swagger와 연동된 실제 배포를 수행하는 대화형 인터페이스 구축.
결과를 한국어 마크다운 형태로 시각화하고 Swagger 문서 최적화로 명령 인식률 향상.

성과
API 실행 성공률 70% → 88% 자연어 명령으로 누구나 배포 가능 오픈소스 개발자대회 우수작 선정

② 빌드 실패 로그 분석 자동화

문제 상황

Jenkins 빌드 실패 시 로그가 방대하고 복잡해 Jenkins를 잘 모르는 사용자는 원인 파악이 어려움.

조치 사항

빌드 실패 로그를 OpenAI ChatGPT에 전달하되, 프롬프트에 출력 규칙(문제 요약 → 원인 → 해결 방안 → 재발 방지 → 핵심 로그)을 명시해 일관된 분석 응답 생성.

성과
분석 과정 표준화 로그 해석 시간 단축 대응 속도 및 협업 효율 향상

③ 공통 모듈 설계를 통한 협업 개선

문제 상황

Jenkins API 호출 시마다 인증·헤더 설정·오류 처리를 반복해야 하는 비효율로 기능별 개발 속도 저하 및 유지보수성 하락.

조치 사항

공통 모듈 HttpClientService를 설계해 인증, 헤더, 오류 처리 로직을 통합 및 재사용 가능하게 만들고, 사용 매뉴얼 문서화로 팀 전반의 적응을 지원.

성과
코드 일관성·개발 효율 향상 중복 코드 제거 팀 전체 생산성 향상
Agentica OpenAI API Jenkins Swagger Docker Kubernetes
인프라 설계

무중단 배포 환경 구축

지속 가능한 IT 인프라 설계 · Jenkins + Kubernetes + Blue-Green

99.9% 가용성
문제 상황

배포 중에도 안정적으로 서비스를 운영할 수 있는 구조가 필요했습니다. 서비스 가용성을 보장하는 인프라 설계가 핵심 과제.

조치 사항

GitHub 웹훅으로 코드가 푸시되면 Jenkins가 자동으로 빌드·테스트를 수행하고, Docker 이미지를 생성해 Kubernetes 클러스터에 자동 배포되도록 구성.
Blue-Green Deployment 전략 적용으로 새 버전 배포 중에도 기존 서비스 무중단 운영.
Jenkins에 Discord 플러그인을 연동해 배포 결과를 팀 채널에 자동 공유하고, 트래픽 전환 상태를 실시간으로 시각화하는 모니터링 스크립트 작성.

성과
서비스 가용성 99.9% 달성 배포 과정 서비스 중단 없음 Discord 자동 배포 알림 구현
